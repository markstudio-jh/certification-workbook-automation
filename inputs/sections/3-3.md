## 이행 항목의 설정

예시 계약의 담당자는 이행을 확인하기 위한 항목을 사전에 정한다. 항목은 납품 대상, 확인 역할, 기록 위치처럼 절차를 설명하는 일반 정보로 구성한다.

각 항목에는 확인 전, 확인 중, 확인 완료와 같은 가상 상태를 부여한다. 담당자는 상태만 변경하지 않고 확인 근거와 다음 조치를 함께 기록한다.

[PDF 페이지 6]

## 변경과 완료 확인

이행 조건을 바꿀 필요가 생기면 담당자는 변경 사유와 영향을 먼저 기록한다. 변경 기록은 최초 기록을 덮어쓰지 않고 이전 상태와 새 상태를 함께 확인할 수 있도록 유지한다.

모든 항목이 확인되면 완료 역할이 기록의 누락 여부를 검토한다. 누락이 있으면 완료 처리하지 않고 해당 항목을 보완 대상으로 되돌린다.

이 가상 예시에는 실제 기관명, 법령명, 금액, 기한 또는 원본 교재 문장이 포함되어 있지 않다.
