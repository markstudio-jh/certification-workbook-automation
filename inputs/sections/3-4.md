## 품목 정보의 구성

예시 시스템은 품목을 구분하기 위해 품목명, 분류 역할, 상태와 설명을 기록한다. 같은 품목을 여러 이름으로 중복 등록하지 않도록 신규 등록 전에 기존 항목을 검색한다.

품목 설명은 특정 공급자나 실제 제품을 가리키지 않는 가상 문장으로 작성한다. 분류 기준이 불명확하면 임의로 확정하지 않고 검토 대상으로 표시한다.

## 정보 변경과 이력

품목 정보가 바뀌면 변경 전 값, 변경 후 값, 변경 사유와 검토 역할을 이력에 남긴다. 사용 중인 품목 정보는 영향 범위를 확인한 뒤 변경한다.

더 이상 사용하지 않는 항목은 즉시 삭제하는 대신 비활성 상태로 전환한다. 이력을 통해 과거 기록이 어떤 품목 정보를 사용했는지 확인할 수 있도록 유지한다.

이 가상 예시에는 실제 기관명, 법령명, 금액, 기한 또는 원본 교재 문장이 포함되어 있지 않다.
