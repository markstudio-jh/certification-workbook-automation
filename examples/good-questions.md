# 예상문제

1. 예시 개념 A에 관한 설명으로 옳은 것은?

① 설명 A
② 설명 B
③ 설명 C
④ 설명 D

정답: ①
근거: 예시 원문은 설명 A를 예시 개념 A의 올바른 설명으로 제시한다. [PDF 페이지 1]
★ 함정: 설명 B와 예시 개념 A를 혼동하지 않도록 한다.

2. 예시 절차의 두 번째 단계에 해당하는 것은?

① 단계 A
② 단계 B
③ 단계 C
④ 단계 D

정답: ②
근거: 예시 원문에 따르면 예시 절차의 두 번째 단계는 단계 B이다. [PDF 페이지 2]
★ 함정: 절차의 순서를 바꾸어 묻는 선택지에 주의한다.

3. 예시 기준에 부합하는 것은?

① 기준 외 항목 A
② 기준 외 항목 B
③ 기준 충족 항목
④ 기준 외 항목 D

정답: ③
근거: 예시 원문은 기준 충족 항목을 예시 기준에 부합하는 항목으로 설명한다. [PDF 페이지 3]
★ 함정: 관련이 있지만 기준을 충족하지 않는 항목과 구분한다.

4. 예시 수치로 옳은 것은?

① 10
② 20
③ 30
④ 40

정답: ④
근거: 예시 원문에 제시된 예시 수치는 40이다. [PDF 페이지 4]
★ 함정: 인접한 수치 30을 정답으로 오인하지 않도록 한다.
