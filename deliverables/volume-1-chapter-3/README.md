# 1권 3장 공개용 가상 샘플 문제집

자동화 파이프라인 입력 형식을 검증하기 위해 **새로 작성한 가상 샘플**입니다. 실제 교재가 아닙니다.

## 제출 파일

- [대화형 HTML 문제집](./1권_3장_공개용_가상샘플_48문제.html) — 브라우저에서 답안 선택·채점·절 필터·해설 확인 가능
- [Markdown](./1권_3장_공개용_가상샘플_48문제.md) — 예상문제 및 해설

절 원문은 저장소의 `inputs/sections/3-1.md`~`3-4.md`에 함께 공개돼 있어 새 체크아웃에서 바로 파이프라인을 실행할 수 있습니다.

## 범위

- 제1절 계약 방식의 기초
- 제2절 전자 구매 절차
- 제3절 계약 이행 기록
- 제4절 품목 정보 관리

## 검증 결과

- 통합 문제 G3: PASS
- 문제 수: 48문항
- 정답 표기: 48/48
- 정답 근거: 48/48
- PDF 페이지 근거: 48/48
- 최대 정답 위치 비율: 25.00% (기준 50% 이하)

## Markdown 판 생성 방식

공개된 대화형 HTML에서 문항·정답·근거·함정을 그대로 추출해 Markdown으로 재구성했습니다. 이 과정에서 근거 표기를 `[원문 PDF 페이지 N]`·`[근거: 원문 PDF 페이지 N]`에서 현행 G3 표준인 `[PDF 페이지 N]`으로 통일했습니다(24건). 문항·선택지·정답·해설 문구는 변경하지 않았습니다.

교재 본문(제1부)은 가상 샘플의 절 원문으로 대체되며 이 폴더에 포함하지 않습니다.
